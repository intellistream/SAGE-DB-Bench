\section{Conclusion}
We present \system, a lightweight dynamic acceleration plugin for ANNS under updates. 
\system stores historical search state as seeds and manages them in a store--retrieve--validate pipeline to guide the post-update query process. Experiments show that \system consistently improves query throughput, preserves competitive recall, and remains robust under dynamic workloads. These results highlight the effectiveness of reusing and validating historical seeds for efficient and reliable query processing.
